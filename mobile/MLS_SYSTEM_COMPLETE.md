## 📊 **GELİŞMİŞ ANALİTİK**

### 🎯 **Performans Metrikleri:**
```dart
// Detaylı analitikler
class MLSAnalytics {
  final int views;
  final int leads;
  final int clicks;
  final int conversions;
  final double revenue;
  final MLSPlatformType platform;
  
  double get clickThroughRate => views > 0 ? clicks / views : 0.0;
  double get leadConversionRate => clicks > 0 ? leads / clicks : 0.0;
  double get salesConversionRate => leads > 0 ? conversions / leads : 0.0;
}
```

### 📈 **Pazar Analitiği:**
```dart
// Pazar verileri
class MLSMarketData {
  final String region;
  final double averagePrice;
  final int totalInventory;
  final int daysOnMarket;
  final double pricePerSquareFoot;
  final int newListings;
  final int soldListings;
  
  double get absorptionRate => totalInventory > 0 ? soldListings / totalInventory : 0.0;
  double get monthsOfInventory => soldListings > 0 ? totalInventory / soldListings : 0.0;
}
```
